\chapter{Detailed Database Schema}
\label{app:db-schema}

This appendix reproduces the canonical PostgreSQL schema of the platform,
exactly as applied to the Supabase project. It is the single source of truth
referenced throughout Chapter~\ref{cap:design}
(Section~\ref{sec:design-database}) and is generated from
\texttt{supabase/migrations/00000000000000\_schema.sql}. The schema
consolidates the enumerated types and the 33 tables together with their
triggers, indexes and foreign-key constraints. Row-Level Security is
intentionally disabled on every application table: all database access is
performed server-side through the service-role key, as discussed in
Section~\ref{sec:design-security}.
